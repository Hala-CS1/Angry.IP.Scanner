# 🛡️ Angry IP Scanner

A hands-on report analyzing **Angry IP Scanner**, comparing it with other network utilities, and demonstrating its deployment on Kali Linux via VirtualBox.

## Features & Summary
* **Purpose:** Lightweight, fast IP and port scanning.
* **Environment:** Kali Linux VM (VirtualBox).
* **Scan Results:** Scanned 254 IPs (`10.0.2.0/24`) in 14.16s, discovering 3 active hosts.

## Status Indicators
* 🔴 **Red:** Inactive host.
* 🔵 **Blue:** Active host (no open ports).
* 🟢 **Green:** Active host with open ports.
